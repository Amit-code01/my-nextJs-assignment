# 🛍️ Next.js Product Management App

A modern **Next.js 16** web application built with **Material UI (MUI v6)** — demonstrating **SSG, SSR, ISR, and CSR** rendering techniques with full CRUD functionality using Next.js API routes and local JSON storage.

> 💡 This project showcases complete front-end and back-end integration using the latest Next.js features and a clean MUI design — perfect for real-world product management systems.

---

## 🚀 Key Features

- ⚡ **Static Site Generation (SSG)** – Product listing on the Home page (`/`)
- ♻️ **Incremental Static Regeneration (ISR)** – Dynamic product details (`/products/[slug]`)
- 💼 **Server-Side Rendering (SSR)** – Real-time inventory dashboard (`/dashboard`)
- 🧾 **Client-Side Rendering (CSR)** – Admin panel for adding products (`/admin`)
- 🔗 **API Routes (Next.js Backend)** – `GET`, `POST`, `PUT` endpoints for managing data
- 💾 **Local JSON Storage** – Products stored and updated via Node.js `fs` module
- 🎨 **Material UI (MUI v6)** – Fully responsive, modern, and elegant design
